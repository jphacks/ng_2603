# プロダクト名: おかん通知

## 製品概要: ひとことで言うと通知を送るアプリである。長時間スマホを眺めている人たちに通知を送ることで、意識を現実に引き戻すことを目的としている。これは「ただ通知をおくる」というアプリではない。「おかん」からの通知である。スマホ触っているときに、急に母親が部屋に入ってきたり、通知が来たりすると、気分が少し悪くなる経験がある。その人間心理を利用し、「おかん」からの通知を再現することで、スマホへの依存を抑えられると考えた。
### 背景(製品開発のきっかけ、課題等）: 最近ドーパミン中毒者（ドパガキ）という言葉を耳にする。我々にもスマホをただただ眺めて時間を費やしてしまったという経験はないだろうか？そういった「スマホ自体」から離れたいと思う人たちに向けて、解決するためのアプリを作ってみようと思った。
### 製品説明（具体的な製品の説明）: 通知が来るタイミングは次のように設定できる。「設定した時間以上スマホを使っていると通知が来る」、「設定した時間内でスマホを使用したら、通知が来る」。見守り開始設定の「今やらなくてはならないこと」を書くことで、通知をするときにそこで書かれた内容も表示されるので、スマホ使用中に、「後回しにしていたこと」や「今日やらなくてはいけないこと」などを思い出し、スマホからその予定へ意識を変えることができる。「おかんのタイプ」を設定することで、通知の頻度や口調などが変わる。設定には３つのモード（甘め、標準、鬼）が存在し、絶対にその日スマホから離れたい人は、「鬼」がオススメ。また「自分自身で管理」するだけでなく、「親子」でつなげて使うことができる。親が上記の内容を設定し、子のスマホを制限することができる。
### 特長
#### 1. 特長1: 約束を破ってスマホを使用してると、「おかん」からの通知がくる
#### 2. 特長2: だれかに強いられることなく、自分の意志でやめるという機会を与えられる 
#### 3. 特長3: 「スマホより今やるべきこと」を通知を介して、思い出すことができる。

### 解決出来ること: 「スマホをつい長時間みてしまうが、それを自らの意思でやめたい人と子供を管理したい親」をターゲットとし、既存するアプリである「設定した時間が来るとアプリ自体をロックする」といった機械技術によって強制的にスマホからはなれさせるのではなく、あくまで「親からの通知」が来た際の精神状況を利用し自らの意思でスマホ依存から抜け出すといった設計にしました、それにより無意識に長時間スマホを見ている人が通知を目にし我に返らせることで、自らの意思でスマホ依存からの脱却ができる。今行うべき今後行うべきを自らの力で作り出すことができるようになる等。
### 今後の展望: 通知内容の追加設定を実装。（反映させるアプリの指定や、使わない時間帯、音の内容など）
### 注力したこと（こだわり等）
* アプリが閉じられても、バックグラウンドで動き続け、他アプリの使用を検知できること
* 強制停止ボタンを実装し、ボタンを押すとアプリを消すことができる
* 親と子の連携にQRコード認証を実装できそうなところまで行いました
